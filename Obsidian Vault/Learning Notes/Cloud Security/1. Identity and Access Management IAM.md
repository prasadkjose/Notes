## Definitions
1. AuthN - Confirm identity
	1. Credentials
	2. API keys
	3. OAuth 2.0 tokens
	4. Instance Principals
	5. Federated Identity
	6. MFA
2. Authz - permissions and policies
	1. Policies define permissions to user and instances
## Identity Domain -
1. logical  Containers for **users, groups** 
2. It's a resource in OCI
3. Lifecycle Management for identity
4. Use 3rd party identity directories
5. Supports SAML and bridges. 
6. SSO, MFA can be added 
7. Types:
	1. Free - 2k user limit - limited support
	2. Oracle Apps premium - free with oracle apps like vbcs - supports hybrid
	3. Premium - unlimited IAM
	4. External user - non employees, hybrid. 
8. Default Domain 
	1. Created by default when creating tenancy
	2. can't be deleted or deactivated. 
	3. replicated to all regions
	4. users - admin and domain user
9. Custom Identity domains
	1. needed for isolation of admin controls
	2. Example - production and dev
	3. every domain should have a domain admin to 
		1. manage user, groups, apps etc
		2. MFA
		3. create self-registration profiles
